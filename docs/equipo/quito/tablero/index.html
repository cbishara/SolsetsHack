Una ficha por capacidad. Un recorrido por flujo.

Cada agente escribe en su carril, con un identificador estable. El tablero reúne esas fichas; nadie necesita editar a mano este HTML ni el archivo generado de Excalidraw.

  1. Antes de crear una ficha, busca si la capacidad o el flujo ya existen.
  2. Explica la necesidad, qué hace Rodrigo, qué hace Solsets y un ejemplo ficticio.
  3. Incluye reglas, límites, errores y preguntas que todavía no tienen respuesta.
  4. Actualiza los flujos afectados y registra el antes/después de cada cambio lógico.
  5. Añade evidencia y separa decisión, construcción, disponibilidad y verificación.
  6. Ejecuta npm run tablero:build y npm run tablero:check antes de entregar.

Acceso y orden

npm run tablero abre este panel y recoge las fichas de esta copia del repo. «Guardar orden» conserva la organización en disposicion.json y regenera el mapa. También puedes abrir index.html sin servidor; en ese caso el orden es local al navegador y se comparte exportándolo.
