# Criterio común de urgencia

El criterio que vale para todos los usuarios, antes de personalizarlo. Se construye con casos borde: Quito da el veredicto de cada caso y el caso pasa a ser una prueba del agente. Lo de cada persona va encima de esto, en su memoria.

Las decisiones posibles: DESPERTAR (lo despierta ahora), PARTE (aviso para la mañana) y RUIDO (no hace falta ni el aviso).

## Casos

1. Un aviso que dice explícitamente "urgente". DESPERTAR. Lo dijo Quito el 2026-10-23.
2. Un pedido banal para otro día, como "oye, necesito que mañana hagas tal cosa". PARTE, como aviso para mañana. Lo dijo Quito el 2026-10-23.

## Casos borde por resolver

Todavía ninguno.
